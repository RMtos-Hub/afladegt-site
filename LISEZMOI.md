# Site web de l'AFLADEGT

Site statique (HTML/CSS) de l'Association des Féministes Leaders pour l'Accès aux Droits et à l'Équité du Genre au Tchad.

## Contenu
- `index.html` : accueil
- `qui-sommes-nous.html`, `nos-combats.html`, `nos-realisations.html`, `actualites.html`, `agir.html`, `contact.html`, `merci.html`
- `assets/` : style, script, logos

## Hébergement
Cloudflare Pages, relié à ce dépôt GitHub.
Réglages : aucun framework, commande de build vide, dossier de sortie `/`.
Chaque modification enregistrée sur GitHub met le site à jour automatiquement.

## Formulaires
Les formulaires ouvrent un e-mail prérempli vers afladegt@gmail.com.
